# gcloud config get-value

## NAME

    gcloud config get-value - alias for gcloud config get, for backwards
        compatibility

## SYNOPSIS

```bash
    gcloud config get-value SECTION/PROPERTY [GCLOUD_WIDE_FLAG ...]

```

## DESCRIPTION

    Alias for gcloud config get, for backwards compatibility.

## POSITIONAL ARGUMENTS

     SECTION/PROPERTY
        The property to be fetched. Note that SECTION/ is optional while
        referring to properties in the core section.

## GCLOUD WIDE FLAGS

    These flags are available to all commands: --access-token-file, --account,
    --billing-project, --configuration, --flags-file, --flatten, --format,
    --help, --impersonate-service-account, --log-http, --project, --quiet,
    --trace-token, --user-output-enabled, --verbosity.

    Run $ gcloud help for details.
